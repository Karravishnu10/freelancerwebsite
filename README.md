# 💼 Freelancer Website

A fully responsive **Freelancer Platform** web application built with pure HTML5 and JavaScript — connecting clients with freelancers through job listings, contracts, messaging, and payments. Live and deployed on **Vercel**.

🌐 **Live Demo:** [freelancerwebsite-mu.vercel.app](https://freelancerwebsite-mu.vercel.app)

## ✨ Features

- 🔐 **User Authentication** — Login page for clients and freelancers
- 👤 **Profile Management** — View and manage user profiles
- 🔍 **Freelancer Search** — Browse and discover freelancers by skill
- 📋 **Job Listings** — View all available job postings
- ➕ **Create Job Listings** — Post new projects and jobs for freelancers
- 📝 **Contract Management** — Manage contracts between clients and freelancers
- 💬 **Messaging** — Real-time in-app messaging between users
- 💳 **Payment Dashboard** — Track payments, earnings, and transactions
- ❓ **Help Center** — Support and FAQ page for users
- 🧭 **Dynamic Navbar** — Reusable navigation component powered by `navbar.js`

## 🚀 Getting Started

No build tools or dependencies required — this is a pure HTML/JS project!

### Run Locally

1. **Clone the repository:**
```bash
   git clone https://github.com/Karravishnu10/freelancerwebsite.git
   cd freelancerwebsite
```

2. **Open in browser:**
   - Simply open `index.html` in your browser, or
   - Use the VS Code **Live Server** extension for a better experience:
     - Right-click `index.html` → **Open with Live Server**

## ☁️ Deployment

This project is deployed on **Vercel** for free hosting.

To deploy your own version:

1. Push your code to GitHub
2. Go to [vercel.com](https://vercel.com) and import your repository
3. Vercel auto-detects the static site and deploys instantly

🔗 **Live URL:** [https://freelancerwebsite-mu.vercel.app](https://freelancerwebsite-mu.vercel.app)
